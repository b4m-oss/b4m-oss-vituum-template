Vite + Vituum + Twig のマルチページ静的サイト雛形をスキャフォールドします。

## Usage

```shell
npx @b4moss/mpa-html-site-starter my-site
cd my-site
npm i
npm run dev
```

## Scripts（生成後のプロジェクト）

| Script | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバ |
| `npm run build` | 本番ビルド |
| `npm run preview` | ビルド結果のプレビュー |
